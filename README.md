# avatar-branches

「説明の枝」（結果のあとに、次に聞きたくなる質問への、用意した答え）の、調査ジョブの出力置き場です。

- `latest.json` … 最新の調査結果（変更・新規の枝だけの JSON 配列）。社内のアバターのサーバーが、6時間ごとに確認し、**下書きとして**取り込みます（承認するまで公開されません）。
- 調査ジョブ（Claude の予約タスク）が、毎週、更新します。ブランチは `claude/branches-latest` です。
- 中身は、公的な情報（金融庁・国税庁・日本年金機構・日本銀行 など）から作った下書きだけです。お客様の情報は入りません。
